# LazyRemote 2.2 beta 1 (iPhone)

## What's new

- Landscape mode: turn your iPhone sideways, in either direction, and the trackpad fills the whole screen with the controls tucked into a column out of its way. Rotating keeps your keyboard, typed text and gestures going.
- Keyboard is now a floating tool next to Remote. Tap it to open a clean typing bar; drag it anywhere to float it, or drop it back into its spot.
- The always-visible text bar is gone, so the trackpad gets more room. Typing happens in the new Keyboard view, with Close and Send buttons.
- Send lights up only when there is text to send and you are connected.
- Remote and Keyboard get out of each other's way and hide while Keyboard or Spotlight is open.
- When you are not connected, the tools dim and ignore taps.

## Mac app

No Mac update is needed. This release works with the Mac app you already have; only the iPhone app changes.
