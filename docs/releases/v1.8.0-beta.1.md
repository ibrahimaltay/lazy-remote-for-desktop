# LazyRemote 1.8 beta 1 (iPhone)

## What's new

- The on-screen arrow keys (D-pad) no longer close by accident. Tapping the empty space around them now shows a short "Tap again to close" hint, and a second tap within a second closes it.
- Swiping across the empty space no longer closes the D-pad.
- The X button still closes it with a single tap.

## Mac app

No changes. Version 1.5 of the Mac app works with this release.
