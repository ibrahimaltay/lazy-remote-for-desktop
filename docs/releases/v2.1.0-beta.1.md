# LazyRemote 2.1 beta 1 (iPhone and Mac)

## What's new

- Live keyboard: type on your iPhone keyboard and the text appears on your Mac as you type, in whatever field is active.
- A Send button sits in the keyboard bar, shown only while the keyboard is open, so you can send what you typed with one tap.
- The remote icon dims while the keyboard is open, and tapping the keyboard row focuses it.
- The Send button and text field now move smoothly together with the keyboard.

## Mac app

This release needs both apps updated. Install Mac app version 2.1 and iPhone app version 2.1 together; the live keyboard does not work with older versions of the Mac app.
