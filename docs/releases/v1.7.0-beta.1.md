# LazyRemote 1.7 beta 1 (iPhone)

## What's new

- Right-click now works like the trackpad on your MacBook: tap once with two fingers. There is no waiting for a second tap, so the context menu appears right away.
- Tapping twice with two fingers is no longer a special gesture. It simply sends two right-clicks.
- The gesture hint text is gone from the trackpad, so there is more clean space to use.

## Mac app

No changes. Version 1.5 of the Mac app works with this release.
